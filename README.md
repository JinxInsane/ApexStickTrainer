# Apex Stick Trainer — Android Native v0.2

Native Android controller aim trainer prototype.

## v0.2
- 360° tracking target around the player
- Minimal Aim-Lab-style void scene
- Six floating targets inside an invisible angular boundary
- 120° horizontal FOV projection
- Strict linear right-stick mapping by default
- 0 deadzone by default
- Fixed/random tracking speed with configurable min/max

Builds automatically with GitHub Actions and uploads a debug APK artifact.
